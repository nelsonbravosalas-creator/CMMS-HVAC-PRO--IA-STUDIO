# Política de seguridad para dispositivos y trabajo offline

Esta política aplica a teléfonos, tablets y computadores que almacenen temporalmente datos del CMMS para operar sin conexión.

## Requisitos del dispositivo

- Cifrado del dispositivo habilitado y sistema operativo con soporte de seguridad vigente.
- Bloqueo automático en un máximo de 5 minutos, protegido con PIN, contraseña o biometría.
- Prohibido usar dispositivos rooteados, con *jailbreak* o compartidos entre personas.
- Navegador y PWA actualizados; no instalar la aplicación desde fuentes distintas al sitio oficial.
- Capacidad de bloqueo o borrado remoto para equipos corporativos.

## Uso del CMMS

- Cada persona debe usar su propia cuenta; no se comparten PIN ni sesiones.
- Cerrar sesión al entregar, cambiar o dejar de usar el dispositivo. El cierre elimina la base local del CMMS.
- Completar la sincronización antes de cambiar de cliente. El sistema bloquea el cambio si existen operaciones pendientes.
- No exportar documentos a carpetas o aplicaciones personales.
- El trabajo offline debe sincronizarse al recuperar conexión y no mantenerse pendiente más de 24 horas.

## Pérdida, robo o sospecha de acceso

1. Informar inmediatamente al administrador del CMMS.
2. Desactivar la cuenta afectada y revocar sus sesiones desde Administración de usuarios.
3. Ejecutar el bloqueo o borrado remoto del dispositivo.
4. Revisar los eventos de seguridad, sincronizaciones y cambios efectuados por la cuenta.
5. Documentar el incidente y cambiar credenciales antes de reactivar el acceso.

## Responsabilidades

- El administrador mantiene usuarios, roles, sesiones y procedimiento de bajas.
- El responsable de TI aplica cifrado, actualizaciones y borrado remoto.
- El usuario custodia el dispositivo y reporta incidentes sin demora.

El almacenamiento local permite la continuidad offline, pero no sustituye los controles del sistema operativo. Para información contractual especialmente sensible se debe evaluar cifrado de campos en la aplicación o impedir su disponibilidad offline.
